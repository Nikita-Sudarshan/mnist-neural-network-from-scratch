# MNIST Neural Network from Scratch

A neural network built from scratch using only NumPy and mathematical operations
for handwritten digit classification on the MNIST dataset.

## What I Implemented

- Forward propagation
- ReLU activation
- Softmax
- One-hot encoding
- Backpropagation
- Gradient descent
- Parameter updates
- Accuracy evaluation

## Tech Stack

- Python
- NumPy
- Kaggle

## Dataset

MNIST handwritten digit dataset.

## Results

Test Accuracy: 83.9%
